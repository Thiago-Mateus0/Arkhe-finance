# Issue tracker: GitHub

Issues deste repo vivem no GitHub (`Thiago-Mateus0/finan-as`). Em sessões sem a CLI `gh`, use as ferramentas do GitHub disponíveis; o contrato é o mesmo.

## Convenções

- **Criar:** título curto + corpo com **Contexto**, **Critério de pronto** (observável) e **Fora do escopo**.
- **Labels:** `fase-3`…`fase-6` (a fase que a issue pertence), `decisao` (espera o Thiago; traz opções e recomendação), `bug`.
- **Fechar pelo PR:** escreva `Closes #N` **em inglês** no corpo — "Fecha #N" não fecha nada.
- Uma issue = um PR pequeno.

## Quando uma skill disser "publicar no issue tracker"
Criar uma issue no GitHub.
