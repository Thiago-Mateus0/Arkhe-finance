# ADR 0016 — Nome do app: Arkhe Finance

- **Status:** Aceito
- **Data:** 2026-10-10
- **Fase:** 2 — Design (marca)
- **Decidido por:** Thiago

## Contexto

O ADR 0014 manteve o nome "Finanças" e registrou que ele era genérico (pendência P11). O projeto também é portfólio e precisa de um nome próprio.

## Decisão

O app se chama **Arkhe Finance**. Na instalação como app (PWA), o nome curto é **Arkhe**. A identidade visual do ADR 0014 não muda.

## Consequências

- Revoga apenas o trecho "Nome mantido: Finanças" do ADR 0014; o resto dele continua valendo.
- Nome muda em título, logo, manifest, README e CLAUDE.md. O pacote Python continua `financas`, porque é nome interno e trocá-lo não agrega nada.
- Vocabulário do domínio segue em português (regra 7); o nome é de marca, não de domínio.
- As capturas em `docs/img/` mostram o nome antigo até serem refeitas.
